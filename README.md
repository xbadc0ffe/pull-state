# Pull State

A precision logbook for your espresso practice — track every shot, dial in your beans, watch yourself improve.

## Features

- Log shots with a dual-track pre-infusion + pull timer
- Per-bean recipes that auto-preload dose, yield, temperature, and pressure on the Log screen
- Bean library with rating-trend sparklines and editable recipes
- Hardware library for espresso machines and grinders, with shot counts
- Filter and sort shot history by extraction, rating, bean, machine, or grinder
- Light, dark, and system appearance — selectable on first run and from About
- Photo attachments for shots, optional tip jar via in-app purchase

## Tech Stack

- **SwiftUI** — declarative UI, custom design system
- **SwiftData** — local persistence, no third-party dependencies
- **iOS 18** — minimum deployment target
- **Multiplatform** — iPhone and iPad, single Swift codebase
